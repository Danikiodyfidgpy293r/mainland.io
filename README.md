MAINLAND — обновлённый комплект v6

Состав архива:
- index.html — интерфейс
- style.css — стили
- app.js — логика приложения

Изменения v6:
1. Журнал событий группы/канала: сообщения о вступлении, добавлении, удалении и выходе участника.
2. Аватар сообщества теперь используется в общем списке чатов, поиске и заголовке открытого чата, а не только в настройках.
3. Разделитель «Новые сообщения»: появляется перед первым непрочитанным входящим сообщением; убирается после прокрутки к концу чата.
4. Панель настроек сообщества скрыта от обычных участников. Создатель и назначенные администраторы видят настройки и управление участниками.
5. Только создатель может назначать/снимать администраторов и удалять сообщество. Администраторы могут управлять настройками и участниками в рамках доступных полномочий.


Ограничение:
Это локальная браузерная демонстрация. События, участники, аватары и настройки хранятся локально и не синхронизируются между разными устройствами или браузерами. Для реальной многопользовательской работы нужен сервер и база данных. Выполнены статические проверки; полноценный браузерный тест не проводился.


Версия v6: интерфейс выровнен по верхнему краю; на широких экранах — Telegram-inspired desktop layout. В профиле группы/канала добавлен просмотр участников для всех участников. Нажатие на участника открывает его профиль; управление администраторами остаётся доступно только уполномоченным.
